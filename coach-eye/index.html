Option A · Run the pipeline, then serve this folder
# 1. split + crop your course videos into quiz clips
python3 pipeline/process_videos.py /path/to/your/videos

# 2. serve the quiz folder over http
cd hyrox-quiz/quiz
python3 -m http.server 8000

# 3. open http://localhost:8000 in your browser

The quiz needs to be served over http:// so the browser may fetch manifest.json and the clip files. Any local server works; python3 -m http.server ships with Python.

Option B · Import your clips into this browser

Already processed your videos? Import the quiz folder (the one containing manifest.json and clips/). The clips are stored in this browser on this device — nothing is uploaded anywhere — and from then on this page just works, no server needed. Re-import any time after processing new videos.

On a phone there is no folder picker: copy the quiz folder to your device, tap Import files, and select manifest.json together with everything inside clips/.

Option C · Get clips from Google Drive

Already uploaded your clips to Drive from another device? One tap brings them here.

AI review of your coaching (optional)

Sync across devices

Keeps your stats, labels, notes, settings and API key in a private GitHub gist so your phone, tablet and computer all see the same data. If you already use sync on the HYROX L2 study site, it turns on here automatically with the same token. Clips are not synced — import them once per device.

Create one at github.com → Settings → Developer settings → Personal access tokens (classic) with only the gist scope, then paste the same token on each device.

Clips in Google Drive

Upload your imported clips to your own Google Drive once, then every device just presses Get clips from Drive instead of importing the folder again. The app only ever sees the files it created (a "Coach Eye Clips" folder).

One-time setup: at console.cloud.google.com create a (free) project → enable the Google Drive API → OAuth consent screen (External) → under Audience press Publish app (this app only asks for the non-sensitive drive.file scope, so publishing needs no Google review; if you stay in Testing you must add your email under Test users and Google makes you re-approve every 7 days) → Credentials → Create OAuth client ID → Web application → add https://dsingson5.github.io as an authorized JavaScript origin → copy the client ID here. It syncs to your other devices automatically.
